## Overview ✨
Juan Online Store is a static e-commerce UI kit with multiple shop layouts.
It includes product pages, blog templates, and a minimal admin dashboard.
All pages are pure HTML/CSS/JS, ready to host anywhere.

## Demo Pages 🧭
- Home: index.html and index-2.html
- Shop: shop.html and grid/list variants
- Product: product-details.html and variants
- Blog: blog-details.html and grid/sidebars
- Checkout flow: cart.html and checkout.html
- Auth: login-register.html and my-account.html
- Utility: compare.html and wishlist.html

## Features 🚀
- Fully responsive layouts for desktop and mobile
- Multiple product detail layouts (simple, group, variable)
- Blog templates with media-focused variants
- Sticky header and slider-ready sections
- Clean admin panel with products and users pages
- Vendor, plugin, and custom styles split for clarity

## Tech Stack 🧰
- HTML5 + semantic sections
- CSS3 with utility-ready structure
- Vanilla JavaScript for interactions
- Vendor libraries bundled in assets

## Getting Started ⚡
1. Open index.html in your browser.
2. Explore shop and product pages.
3. Customize assets/css/style.css for theming.
4. Edit assets/js/active.js for behavior tweaks.

## Folder Structure 🗂️
- /assets/css -> stylesheets
- /assets/js -> scripts and plugins
- /assets/img -> images and media
- /admin panel -> dashboard pages and assets

## Customization 🎨
- Update colors in assets/css/style.css
- Replace hero images in assets/img/slider
- Edit product cards in shop grid pages
- Swap logos in assets/img/logo

## Admin Panel 🧑‍💼
- admin panel/index.html provides dashboard UI
- admin panel/products.html lists catalog items
- admin panel/users.html manages user rows
- admin panel/assets/css/admin.css controls styling

## Accessibility ♿
- Keep alt text meaningful when changing images
- Maintain heading order for screen readers
- Ensure sufficient contrast when changing colors

## Performance Tips ⚙️
- Compress images before replacing assets
- Defer non-critical scripts if extending
- Combine fonts to reduce requests

## Deployment ☁️
- Host on GitHub Pages, Netlify, or any static host
- No build step required
- Works on any server that serves static files
